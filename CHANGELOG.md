# Changelog

Toutes les modifications importantes apportées à **References** seront
documentées dans ce fichier.

Le format s'inspire de [Keep a
Changelog](https://keepachangelog.com/fr/1.1.0/) et le projet suit le
principe du [versionnage sémantique](https://semver.org/lang/fr/).

Les catégories utilisées sont : **Ajouté**, **Modifié**, **Corrigé**,
**Supprimé** et **Sécurité**.

------------------------------------------------------------------------

## \[1.0.0\] --- 2026-09-03

### Ajouté

-   première version stable publique de References ;
-   création de tableaux de références visuelles à partir de liens web ;
-   nom personnalisable du tableau ;
-   catalogue initial externe dans `data/references-default.json` ;
-   catégories personnalisables avec couleurs associées ;
-   mots-clés, descriptions et favoris ;
-   ajout et modification d'une image de vignette ;
-   filtrage par catégorie, mot-clé, favoris et références sans mot-clé
    ;
-   recherche textuelle ;
-   tri par catégorie utilisé par défaut ;
-   autres tris : récent, ancien et alphabétique ;
-   réorganisation manuelle des fiches par glisser-déposer ;
-   import et export JSON ;
-   nom des sauvegardes au format `reference_nom_du_projet.json` ;
-   fusion ou remplacement lors de l'import ;
-   sauvegarde automatique locale via `localStorage` ;
-   restauration du catalogue de références par défaut ;
-   interface bilingue français-anglais ;
-   interface responsive pour ordinateur, tablette et téléphone ;
-   favicon `favicon/favref.png` ;
-   code source commenté et organisé par sections.

### Documentation

-   ajout de `README.md` ;

-   ajout de `ARCHITECTURE.md` ;
-   ajout du présent `CHANGELOG.md` ;

# English summary

## \[1.0.0\] --- 2026-09-03

### Added

-   first stable public release of References;
-   visual reference boards built from web links;
-   custom board names;
-   external default catalogue stored in `data/references-default.json`;
-   customizable categories and colours;
-   tags, descriptions and favourites;
-   custom thumbnail images;
-   search and filtering tools;
-   category sorting selected by default;
-   manual drag-and-drop ordering;
-   JSON import and export;
-   automatic browser local storage;
-   restoration of the default reference catalogue;
-   French-English interface;
-   responsive desktop, tablet and mobile layout;
-   source code documentation and project files.
